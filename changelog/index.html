Changelog

All notable changes to Format JSON are documented here.

v1.2.0 May 25, 2026 Latest

Added

  • JSON Repair / Auto-Fix — A Repair JSON button appears in the validation bar whenever invalid JSON is detected. It automatically fixes the most common mistakes: trailing commas, JavaScript/Python-style comments, single-quoted strings, unquoted object keys, and Python constants (True, False, None).
  • CSV → JSON import — Import any .csv file using the new CSV button in the toolbar. CSV data pasted directly into the editor is also auto-detected and converted to a JSON array of objects. Numbers, booleans, and nulls are inferred automatically from cell values.
  • JSON Statistics panel — After a successful parse, a compact stats bar appears below the validation message showing: total key count, maximum nesting depth, byte size, and a type-breakdown (objects, arrays, strings, numbers, booleans, nulls).
  • JWT Decoder — Paste a JSON Web Token into the editor and a Decode JWT button appears. Clicking it opens a modal showing the decoded header, payload, and raw signature. No secret key required; the signature is not verified.
  • TOML export — Added TOML to the Export dropdown. Scalars are emitted as key = value, nested objects as [section] headers, and arrays of objects as [[table-array]] blocks.
  • SQL INSERT export — Added SQL INSERT to the Export dropdown. Works best with arrays of objects; generates one INSERT INTO statement per row with proper SQL escaping.

Improved

  • Paste detection now converts CSV data automatically without requiring the Import button.
  • File import now accepts .csv files in addition to .json and .txt.
v1.1.0 May 25, 2026

Added

  • Sort Keys — Recursively sorts all object keys alphabetically. Available via the Ctrl+Shift+S shortcut or the Sort Keys button in the editor toolbar.
  • Indent size selector — Choose between 2 spaces, 4 spaces, or a tab character for JSON formatting. Selection is persisted across sessions.
  • Undo / Redo — Up to 50 editor states are tracked. Use Ctrl+Z to undo and Ctrl+Y / Ctrl+Shift+Z to redo any Format, Minify, Sort, or paste action.
  • Keyboard shortcuts modal — Press ? or click the toolbar button to open a full reference of all keyboard shortcuts.
  • URL Content-Type check — When loading JSON from a URL, the tool now warns if the server returns HTML instead of JSON (e.g. a login redirect).
  • OS dark mode auto-detection — The theme now follows the operating system's dark/light preference automatically on first visit. Manually toggling the theme button overrides this for the session.

Improved

  • Format, Minify, Sort, file import, and URL load actions all integrate with undo history so no change is ever unrecoverable.
  • Paste events now respect the selected indent size instead of always defaulting to 2 spaces.
v1.0.0 January 2026 Initial Release

Added

  • JSON Formatter / Beautifier — Paste or type raw JSON and format it with one click.
  • JSON Minifier — Strip all whitespace for compact output.
  • JSON Validator — Real-time syntax validation with inline error messages.
  • Tree Viewer — Interactive collapsible tree with expand/collapse all, search, and node highlighting.
  • JSON Diff / Compare — Side-by-side comparison of two JSON documents with highlighted differences.
  • Code Generator — Generate TypeScript interfaces, Python dataclasses, Go structs, and more from any JSON object.
  • Export — Download formatted JSON, or convert to CSV, YAML, or XML.
  • File import & URL load — Load JSON from a local file or any public URL.
  • Drag & drop — Drop a JSON file directly onto the editor.
  • Dark / light theme — Toggle between themes; preference is saved locally.
  • Internationalization — UI available in English, Dutch (Nederlands), German (Deutsch), and Russian (Русский).
  • PWA support — Installable as a Progressive Web App for offline use.
  • 100% client-side — No data is ever sent to a server.
